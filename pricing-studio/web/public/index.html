01

描述或导入

文字每行一项，写明产品、规格、数量与每资源月用量。支持 CSV/XLSX 标准清单，也支持本次样例格式的 AWS 文字版账单 PDF。

文字由规则解析，无大模型推理。未识别字段留空，等待补充。扫描版 PDF 不支持。

02

核对目标方案

选择华为云目标 SKU。vCPU / 内存接近不代表性能、架构或 SLA 等价。RDS 还需核对引擎、版本与主备配置；CPU ARM / x86、Windows 许可、突发性能均需复核。

EC2 算力费用不包含云硬盘、快照、网络和关联服务，请分别添加。没有目录或计价规则的项目保持 Pending。

03

检查费用与假设

官方已验证价格快照有效期 7 天，可点击在线核价重新获取。选择华为云按需、包月或包年，并确认规格、目标数量及容量后计价。AWS reserved / spot 只作为源账单记录，不会成为华为云目标选项。

账单是累计用量，不能反推资源台数，也不会自动外推整月。来源账期费用与月度预估分开展示。订阅需要明确目标数量和容量，不能把累计使用小时当作台数。包年采用独立官方年价并展示预付金额；月均仅为12个月摊销。

04

导出与留存

Excel 包含 Input、Service Mapping、Public Pricing、Quotation、Assumptions 五张表。Pending 金额为空；部分报价明确标为已验证部分小计。

输入只保留在当前网页内存，刷新后清空。清单和 PDF 不上传服务器。在线询价仅发送华为产品编码与用量，不读取云凭证。

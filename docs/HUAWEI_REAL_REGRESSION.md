## 每次在线更新的记录口径

1. 发布后登记版本、主线提交、验收状态和可比基线。真实验收状态随所有者提交的统计推进。合成测试单独记录。 [开发状态](DEVELOPMENT_STATUS.md)
2. 以相同参考清单比较对应阶段，核对输入行、区域和计费模式计数。记录会影响归因的目录快照变化。
3. 已确认、条件估算、Pending 及其他状态分别计数。Pending 原因按主费用和关联费用分别汇总。按变化最大的可复现原因讨论优先级，并用虚构样例形成新增回归。

共享记录仅需版本、日期、计数和标准原因码。实际报价及工作簿由所有者在隔离环境对账。 [验收入口及校验命令](HUAWEI_PRIVATE_ACCEPTANCE_TEMPLATE.md)
